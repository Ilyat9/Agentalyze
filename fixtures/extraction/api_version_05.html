Acme Public API

The Acme API has been publicly available since version 1.0.0 (2023). Installations still running versions below the minimum supported release receive limited support only.

Current stable API version
2.4.1
Minimum supported API version
1.9.0
Authentication scheme
Bearer tokens
Rate limit
600 requests/min

Roadmap note: beta builds of the upcoming 3.0.0-rc2 are shared with design partners; they are NOT part of the public stable API.
