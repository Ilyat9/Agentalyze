Локальные HTML-фикстуры для агентных задач. Каждая фикстура:

- работает полностью оффлайн (никаких внешних CDN/доменов);
- содержит программно читаемый маркер финального состояния
  (специфичный `id`/`data-*`-атрибут), который проверяет верификатор;
- для `ERROR_RECOVERY` — симулирует «первая попытка не сработает» через
  JS-состояние (поведение задокументировано комментарием внутри файла).

Подпапки соответствуют категориям задач (`navigation/`, `form_fill/`,
`extraction/`, `multi_step/`, `error_recovery/`, `distractor/`). Фикстуры
раздаются локальным HTTP-сервером (`agentalyze.tasks.fixture_server`),
а не через `file://` — см. докстринг модели `Task`.

Проверить все фикстуры программно (Playwright, без агента):

```bash
pytest -m browser            # или: python -m agentalyze.tasks.validate_fixtures
```

Служебные reference-селекторы для этой проверки живут в
`src/agentalyze/tasks/reference.py` и **никогда** не передаются агенту.
