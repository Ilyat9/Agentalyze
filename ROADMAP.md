# Agentalyze — Roadmap

Проект реализуется поэтапно. Каждая фаза — самостоятельный, рабочий шаг;
ничего не пишется «про запас» без контекста.

| Фаза | Описание | Статус |
| ---- | -------- | ------ |
| 0 — Скелет проекта | Структура репозитория, `pyproject.toml`, базовый `config.py` (pydantic-settings), тесты, минимальный CI | ✅ done |
| 1 — Task-suite | Описание задач (реестр из 18 задач, 6 категорий), локальные HTML-фикстуры, HTTP-сервер фикстур, программные верификаторы и валидация фикстур | ✅ done |
| 2 — Provider layer | OpenAI-совместимые API + Ollama | 📋 planned |
| 3 — Раннер | Реальный Chromium, ReAct-цикл, трейсы | 📋 planned |
| 4 — Метрики и failure-таксономия | Не только success rate: где именно ломается агент | 📋 planned |
| 5 — Сравнение моделей и отчёты | Несколько моделей/провайдеров на одном наборе задач | 📋 planned |
| 6 — Regression-режим для CI | Детект регрессий между прогонами | 📋 planned |
| 7 — Docker, GitHub Actions, финальная документация | Расширенный CI, контейнеризация, полные доки | 📋 planned |
