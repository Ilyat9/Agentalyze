Agentalyze — live demo (bring your own key)

A real agent, a real headless Chromium, local benchmark pages — powered by your API key.

How your API key is handled — please read before running anything:
  • The key is sent over HTTPS to this server only when you press “Run”. It is never stored in your browser (no localStorage, no cookies).
  • Processing happens server-side, not in your browser: this server runs a real headless Chromium that drives the task pages, and it calls your provider’s API with your key to make model decisions.
  • The key is used for this single request only, kept in memory for the duration of the run, never logged and never persisted anywhere. It is discarded when your run finishes.
  • Model calls are billed to your own account. Tasks here are deliberately tiny (a few steps) to keep the cost negligible.
  • First run after a quiet period can take up to a minute — the free hosting “sleeps” and wakes up on demand. That’s the platform, not a failure.
Only cloud OpenAI-compatible endpoints are supported. (Ollama/local models are not offered: an anonymous demo cannot reach a model server on your machine.)
