# Agentalyze — Roadmap

Проект строился инкрементально: каждая веха оставляла после себя рабочий,
покрытый тестами код, на который опиралась следующая. Ниже — основные вехи
в порядке их появления.

| Веха | Что появилось |
| ---- | ------------- |
| Скелет проекта | Структура репозитория, `pyproject.toml`, базовый `config.py` (pydantic-settings), тесты, минимальный CI |
| Task suite | Описание задач (реестр из 30 задач, 6 категорий), локальные HTML-фикстуры, HTTP-сервер фикстур, программные верификаторы и валидация фикстур |
| Provider layer | OpenAI-совместимые API + Ollama, retry (tenacity), health-check |
| Раннер | Реальный Chromium, ReAct-цикл, полные трейсы прогона |
| Метрики и failure-таксономия | Не только success rate: где именно ломается агент |
| Сравнение моделей и отчёты | Несколько моделей/провайдеров на одном наборе задач: suite-runner, compare / inspect, report.md |
| Regression-режим для CI | Детект регрессий между прогонами, exit-коды для гейта PR |
| Упаковка и документация | Docker, расширенный GitHub Actions, полные доки |

Всё перечисленное реализовано. Проект презентуется как цельный инструмент в
рамках заявленного скоупа; границы применимости и осознанные упрощения собраны
в [`KNOWN_LIMITATIONS.md`](KNOWN_LIMITATIONS.md). Этот файл сохранён как
исторический документ — по нему видно, как проект обрастал возможностями
от ядра к аналитике и CI-интеграции.
